# tools/simulator

Simulateur par agents d'un corridor (I0.10) : passagers, véhicules, gares, signalements bruités, fraude, pluie. Il sert à tester l'agrégation, les estimations et la charge avant d'avoir des données terrain. Ce dossier s'ajoute à l'arborescence de la partie 9.7 (H-015).

Toute exécution est reproductible à partir d'une graine (`make_rng`).
