# services/channels

Adaptateurs des canaux sans smartphone (partie 11) : WhatsApp, SMS, USSD, serveur vocal, autour d'un moteur de conversation commun.

Déjà disponible : outils GSM 7 bits pour le SMS (partie 11.3). Ils détectent les caractères hors alphabet, translittèrent le français (« wôrô-wôrô » devient « woro-woro ») et comptent les segments pour tenir dans 2 SMS.
