# data/terrain

Données collectées sur le terrain pendant la phase 0 (I0.2). Ce dossier s'ajoute à l'arborescence de la partie 9.7 (hypothèse H-022).

- `modeles/` : modèles CSV vides, à copier pour la saisie. Ils sont générés à partir des schémas : ne pas les modifier à la main.
- `collecte/` : données réelles saisies, validées en intégration continue. Elles sont anonymes et ne contiennent aucune ligne fictive.

Protocoles, fiches et dictionnaire : [docs/TERRAIN](../../docs/TERRAIN/README.md).
